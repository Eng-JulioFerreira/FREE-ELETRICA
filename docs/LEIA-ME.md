# Free Elétrica: leia-me

Projeto elétrico predial de baixa tensão (ABNT NBR 5410), baseado no CADCraft.

## Para começar

1. Clique duas vezes em `FreeEletrica.exe`. Não precisa instalar nada.
2. Se o Windows avisar que o aplicativo é desconhecido, clique em **Mais informações** e **Executar assim mesmo**.
3. Abra sua planta em DXF ou comece um desenho novo, e siga a paleta **Elétrica**, de cima para baixo.

O passo a passo está em `GETTING_STARTED.md`, e a instalação em `INSTALL.md`.

## O que tem aqui

| Item | O quê |
| :--- | :--- |
| `FreeEletrica.exe` | O programa |
| `templates/FREE_ELETRICA_BLOCOS.dxf` | Template opcional: os blocos base entram sozinhos em qualquer desenho |
| `licencas/` | As licenças do Free Elétrica e do CADCraft |

Os resultados apoiam o projeto e precisam da conferência de um profissional habilitado.
